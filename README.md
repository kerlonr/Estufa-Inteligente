## Sobre

Cultivar em estufa exige acompanhar temperatura, umidade e irrigação o tempo todo. A **Estufa
Inteligente** usa sensores e automações no **Home Assistant** para cuidar disso, e ainda serve como
espaço de aprendizado sobre agricultura sustentável.

Este repositório é o **site de apresentação** do projeto.

> Projeto do **Aquário**, setor de automação da Tecnicon.

## O Projeto

- **Sustentabilidade:** hidroponia com tilápias nutrindo as plantas, menos químicos e computadores
  antigos reaproveitados como servidor
- **Educação:** espaço para ensinar práticas agrícolas sustentáveis e nutrição consciente
- **Tecnologia:** ESP32 e Arduino leem os sensores e acionam os equipamentos; o Home Assistant
  reúne os dados e roda as automações
